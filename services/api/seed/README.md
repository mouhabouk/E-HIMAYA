# المرجع الإداري التونسي

| الملف | المحتوى |
|---|---|
| `gouvernorats.csv` | الولايات الـ24 بالرمز الرسمي (ISO 3166-2:TN) والاسم بالعربية والفرنسية |
| `delegations.csv` | 279 معتمدية مرتبة حسب الولاية، بالاسم بالعربية والفرنسية |

**المصدر:** قائمة المعتمديات بالأحرف اللاتينية مأخوذة من صفحة «Delegations of Tunisia» على ويكيبيديا (أكتوبر 2026)، والأسماء العربية مكتوبة يدويا.

**قبل الإطلاق:** يجب مطابقة القائمة مع المرجع الرسمي للمعهد الوطني للإحصاء (INS)، وإضافة الرموز الرسمية للمعتمديات والحدود الجغرافية (طبقة `boundary`). الرمز الحالي للمعتمدية (`TN-61-12`) داخلي ومستقر، ولا يتغير بإضافة الرموز الرسمية في عمود منفصل.

لتعديل القائمة: أضف ترحيلا جديدا (Alembic) يعدّل البيانات. لا تعدّل ترحيل `0002` بعد تطبيقه في أي بيئة.
