# بروتوكول التجربة اليدوية للنفاذ (NFR-10)

الفحص الآلي (P3c و P5a و P5b) يقرأ شجرة الدلالات ويقيس أهداف اللمس والتباين، لكنه لا يسمع ما يقوله قارئ الشاشة.
هذه التجربة تُجرى على هاتف حقيقي، في ساعة تقريبا، ويُستحسن أن يجريها مستعمل يعتمد قارئ الشاشة في يومه، مع جمعية
لذوي الإعاقة البصرية أو السمعية.

## 1. التحضير

| البند | أندرويد | iOS |
|---|---|---|
| الإصدار | 0.17.0 (build 16) أو أحدث | نفسه |
| قارئ الشاشة | الإعدادات ← تسهيل الاستخدام ← TalkBack | الإعدادات ← تسهيل الاستخدام ← VoiceOver |
| الصوت العربي | الإعدادات ← اللغة ← تحويل النص إلى كلام ← تثبيت بيانات الصوت (العربية) | الإعدادات ← تسهيل الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية |
| حجم الخط | الإعدادات ← العرض ← حجم الخط: الأكبر | الإعدادات ← تسهيل الاستخدام ← العرض وحجم النص ← نص أكبر |
| البيئة | خادم التجربة، مع شريط [SIM] الكهرماني | نفسه |

تُعاد التجربة مرتين: بالعربية ثم بالفرنسية (لغة التطبيق من الإعدادات).

## 2. المسارات

لكل خطوة: ما يُفعل، وما يجب أن يُسمع أو يُرى. تُسجَّل النتيجة في الجدول (§3).

### أ. أول تشغيل

1. اختيار اللغة: كل لغة تُقرأ باسمها، والزر «مواصلة» يُقرأ زرا.
2. بطاقات التعريف: يُقرأ «صفحة 1 من 5»، والعنوان يُعلن عنوانا.
3. الميثاق: النص يُقرأ كاملا بالتمرير، ومربع الموافقة يُقرأ مع حالته (محدَّد أو لا).

### ب. النجدة والاتصال

4. الرئيسية: زر النجدة يُقرأ مع «اضغط مطوّلا»، والضغط المطوّل بإصبعين (أو النقر المزدوج مع الإمساك) يرسل.
5. «اتصل بـ 198» يفتح المتصل ولا يتصل وحده.
6. أرقام الطوارئ تُقرأ بالاسم والرقم.

### ج. البلاغ

7. بلاغ جديد: كل صنف يُقرأ باسمه وحالته، الحقول الإجبارية تُعلن «إجباري».
8. إرسال البلاغ: رسالة النجاح ورقم التتبع يُقرآن دون الحاجة إلى البحث عنهما.

### د. التنبيه والقراءة الصوتية (P5a)

9. تنبيه عاجل والتطبيق مفتوح: مع «وميض الشاشة» يظهر الوميض ثلاث مرات ولا يُقرأ؛ مع «قراءة التنبيه» يُقرأ العنوان والنص.
10. زر «استمع» في نصيحة: يقرأ بلغة التطبيق، ويصير «إيقاف القراءة»، والخروج يوقف القراءة.
11. هاتف بلا صوت عربي: رسالة تقول كيف يُثبَّت.

### هـ. الوضع المبسّط (P5b)

12. الإعدادات ← النفاذ ← «الوضع المبسّط»: المفتاح يُقرأ مع حالته.
13. الرئيسية المبسّطة: خمسة أزرار تُقرأ بجملها الكاملة، وعدد التنبيهات يُقرأ مع زر «التنبيهات».
14. بيد واحدة: كل الأزرار في متناول الإبهام دون تغيير وضع اليد (يُجرَّب باليد اليمنى ثم اليسرى).
15. «عرض كل الخيارات» يعيد الرئيسية الكاملة.

### و. مركز الطوارئ والتقييم

16. دليل الإسعافات: الخطوات المرقّمة تُقرأ بترتيبها، وزر «استمع» يقرأ الدليل كله.
17. «قيّم التطبيق»: كل نجمة تُقرأ «3 من 5»، والنجمة المختارة تُقرأ «محدَّدة».

### ز. الخط الكبير

18. بحجم الخط الأكبر: لا نص مقطوع ولا زر خارج الشاشة في الرئيسية، والبلاغ، والإعدادات، والوضع المبسّط.
