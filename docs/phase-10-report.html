3. حدود معروفة

  • GitHub Actions لا يعمل على المستودع الخاص، لذلك شُغّلت الفحوص بـ scripts/ci-local.sh. المهام التي تحتاج Docker (بناء الصور، Trivy، Keycloak الحقيقي، البنية الكاملة) لم تُشغَّل هنا لأن Docker غير متوفر في بيئة العمل؛ تعمل على جهازك أو على مشغل خاص.
  • فحص ZAP الديناميكي يُشغَّل يدويا على بيئة تجريبية كاملة قبل الإصدار، ولم يُشغَّل بعد.
  • محاكاة اختبارات المتصفح تستعمل واجهة برمجية مزيفة ورمز دخول غير موقّع، كما في المراحل السابقة.
  • هذا تقييم ذاتي للأمن. يلزم اختبار اختراق خارجي قبل الإطلاق الوطني.
  • 21 متطلبا من 81 ليس لها اختبار مسمى بعد؛ القائمة في docs/traceability.md.
