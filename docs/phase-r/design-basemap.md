# خلفية الخريطة: القمر الصناعي بمصدر مفتوح ومزوّد مدفوع تختاره الإدارة

طلب يامن (2026-10-28): «اضف زر الانتقال الى وضع القمر الصناعي اعتمادا على مصادر مفتوحة، كذلك قم بتحضير اختيار وضع القمر
الصناعي المدفوع حسب اختيار الإدارة، تبقى تعديلات في إدخال مسار API أو مفتاح الترخيص».

## 1. الفكرة

خلفية واحدة لكل الخرائط بثلاثة أوضاع، ومصدران للصور:

| | المصدر المفتوح (افتراضي) | المزوّد المدفوع (باختيار الإدارة) |
|---|---|---|
| الصور | Sentinel‑2 الخالية من السحب (EOX، 2020)، دقة 10 م | ما تتعاقد عليه الإدارة: Esri أو Maxar أو Mapbox أو Google أو غيرها، دقة أدق وصور أحدث |
| الترخيص | CC BY-NC-SA 4.0: ذكر المصدر إلزامي، والاستعمال غير التجاري (وهو حال الحماية المدنية) | حسب العقد |
| الإعداد | لا شيء | مسار API ومفتاح الترخيص يُدخلهما مدير النظام الوطني |
| أسماء الأماكن في الوضع الهجين | CARTO (OpenStreetMap) | نفسها |

## 2. الزر في الخريطة

مفتاح «خريطة / قمر صناعي / هجين» بجانب طبقات الخريطة الحية. الهجين صور القمر الصناعي مع أسماء المدن والطرق فوقها. يتذكّر
المتصفح اختيار كل مستعمل. الطبقات والمحاور ونتائج البحث تبقى فوق الخلفية كما هي، وتحت المفتاح اسم مصدر الصور الحالي.

## 3. المزوّد المدفوع

تبويب «خلفية الخريطة» في صفحة طبقات بيانات الخريطة، لمدير النظام الوطني وحده:

- **المزوّد**، و**مسار الصور** كما في العقد، بالمواضع `{z}` و`{x}` و`{y}`، و`{key}` في موضع المفتاح إن كان في المسار
  (أو اسم الترويسة إن كان المفتاح يُرسل فيها)، و**ذكر المصدر** الإلزامي، و**أقصى تقريب** يخدمه المزوّد.
- **مفتاح الترخيص**: يُحفظ مشفّرا في قاعدة البيانات (مثل المعطيات الشخصية)، ولا يرجع أبدا من الخادم؛ تظهر آخر أربعة
  أحرف فقط للتعرّف عليه. الحقل الفارغ يُبقي المفتاح، وخانة «حذف المفتاح المحفوظ» تحذفه.
- **تجربة الاتصال** قبل التفعيل: يطلب الخادم صورة واحدة لتونس ويعرض النتيجة والمدة.
- **التفعيل** بخانة واحدة لكل الخرائط. كل تغيير وكل تجربة في سجل التدقيق، دون المفتاح.

### لماذا لا يصل المفتاح إلى المتصفح

لو أُعطي المفتاح للمتصفح لأمكن نسخه واستعماله خارج المنظومة على حساب الإدارة. لذلك يطلب المتصفح كل صورة من الخادم
بعنوان موقّع صالح 12 ساعة (`/api/v1/basemap/tiles/{z}/{x}/{y}?t=…`)، والخادم يجلبها من المزوّد بالمفتاح.

### إذا تعطّل المزوّد

إذا رفض المزوّد الطلب أو انتهى المفتاح أو تجاوز التقريب ما يخدمه، يحوّل الخادم الطلب إلى صورة المصدر المفتوح للمربع
نفسه. الخريطة لا تصير بيضاء أبدا.

## 4. ما بقي

- **حركة المرور**: بالطريقة نفسها (مسار ومفتاح) حين تختار الإدارة المزوّد (TomTom أو HERE أو Google) أو مصدرا رسميا.
- مفتاح الخلفية في خرائط أخرى (لوحة المحور، المحاكاة) يُضاف بالمكوّن نفسه.
- صور لقطات التقرير **[SIM]**: خوادم الصور محجوبة في بيئة البناء، فاللقطات بصور محاكاة مولّدة من حدود الولايات.
