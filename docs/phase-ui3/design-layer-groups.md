# UI-3b: طبقات الخريطة في مجموعات

طلب المالك (28 أكتوبر 2026): الطبقات لا تُعرض في قائمة مسطّحة؛ تُجمع في مجموعات، مثل «المؤسسات الصحية» وفيها
المستشفيات والمصحات والصيدليات، و«موارد الحماية المدنية» (محور R).

## 1. مراجعة

لكل طبقة (`geo.layer`، المرحلة L1a) مفتاح واسم وأيقونة ولون وجماهير ونطاق وحالة، ولا انتماء لمجموعة. لوحة الطبقات في
الخريطة الحية وفي واجهات القيادة قائمة مسطّحة بنحو ثلاثين طبقة، وتطول مع البرامج الموسمية وطبقات البحث في الموارد.

## 2. التصميم

- **المجموعة**: مفتاح، اسم بالعربية والفرنسية والإنجليزية، أيقونة ولون، ترتيب. يديرها مدير المنظومة من صفحة الطبقات
  (إنشاء، تسمية، ترتيب، نقل طبقة من مجموعة إلى أخرى). كل طبقة في مجموعة واحدة؛ الطبقة الجديدة تقترح مجموعتها من أيقونتها.
- **في الخريطة**: مجموعات تُطوى وتُفتح، بعدد الطبقات الظاهرة فيها؛ زر يشغّل المجموعة كلها أو يطفئها، وكل طبقة بمفردها؛
  حالة الطيّ تُحفظ في المتصفح. البحث بالاسم في الطبقات يفتح المجموعة التي فيها النتيجة.
- **الرؤية لا تتغير**: المجموعة لا تمنح حقا؛ كل طبقة تبقى بجماهيرها ونطاقها، والمجموعة التي لا يرى المستخدم فيها شيئا
  لا تظهر له. الطبقات الحساسة في مجموعة لا يراها إلا الوزير.

### 2.1 المجموعات المقترحة أولا

| المجموعة | الطبقات |
|---|---|
| موارد الحماية المدنية | الوحدات، فوهات الإطفاء، الآليات والمعدات والأعوان (R)، نتائج البحث المرحَّلة |
| المؤسسات الصحية | المستشفيات، المصحات، الصيدليات، دور المسنين |
| الأمن | الشرطة، الحرس الوطني |
| الإدارة | مقرات الولايات، مقرات المعتمديات، الوزارات |
| التعليم | المدارس، المعاهد، الكليات، الجامعات |
| النقل | المطارات، محطات القطار، السكك، محطات الحافلات ومواقفها |
| المنشآت الاقتصادية | المصانع، الشركات، محطات الوقود، المساحات التجارية، النزل |
| الماء والغابات | البحيرات، الأودية، الغابات |
| أماكن التجمع | دور العبادة، المنشآت الرياضية |
| المواسم والسواحل | البرامج الموسمية، الشواطئ وخطر الغرق |
| حساسة (الوزير وحده) | الثكنات، المحروقات والغاز |

## 3. مكانها في الخطة

بعد القائمة الرئيسية مباشرة وقبل R1، لأن طبقات الموارد تحتاجها.
