الحاوية لا تشغّل systemd ولا تملك نواتها، فبعض الخطوات كُتبت ملفاتها ولم تُفعَّل (sysctl، auditd بالكامل، fail2ban، rsyslog، AppArmor). لذلك مؤشر 82 حدّ أدنى؛ على خادم Ubuntu حقيقي تُفعَّل هذه الخطوات كلها بالسكريبت نفسه، ويُعاد القياس بالأمر نفسه. فحص ZAP يحتاج Docker، فلم يُجرَ هنا؛ يُجرى على نسخة التجربة بـ infra/security/zap/run.sh (فحص الواجهة البرمجية بحساب عون) وبـ audit.sh (الفحص السلبي للحافة).

2. ما يفعله سكريبت التحصين

sudo infra/security/harden-host.sh --check  --profile demo   # يعرض ما سيتغير، دون كتابة
sudo infra/security/harden-host.sh --apply  --profile demo   # حاسوب العرض: 443 فقط على الشبكة المحلية
sudo ADMIN_NET=10.20.0.0/24 TELEPHONY=1 infra/security/harden-host.sh --apply --profile prod
المجالالإجراء
الحزمufw و auditd و fail2ban و unattended-upgrades و needrestart و debsums و rkhunter و libpam-pwquality و acct و sysstat و rsyslog و chrony
النواة والشبكة‎/etc/sysctl.d/60-ehimaya.conf: حماية مؤشرات النواة، منع إعادة التوجيه ومسارات المصدر، SYN cookies، تسجيل الحزم الشاذة؛ إعادة توجيه IPv4 تبقى لـ Docker
الوحداتتعطيل dccp و sctp و rds و tipc وأنظمة ملفات غير مستعملة و firewire، وتخزين USB (إلا بـ ALLOW_USB_STORAGE=1)
الحساباتumask 027، عمر كلمة السر، 65536 دورة تجزئة، جودة كلمة السر (12 حرفا، 3 أصناف)، لا تفريغ للذاكرة
SSHمفاتيح فقط، لا دخول للجذر، 3 محاولات، لافتة قانونية؛ مع fail2ban (حظر ساعة بعد 5 محاولات)
الجدار الناريرفض كل وارد افتراضيا؛ العرض: 22 و 443 (TCP و UDP) و 8189/udp؛ الإنتاج: يضاف 80 و SIP و RTP عند TELEPHONY=1؛ SSH من ADMIN_NET فقط
التدقيققواعد auditd للهوية والصلاحيات و SSH والوقت و Docker وملف الأسرار ‎.env
Dockerno-new-privileges، live-restore، سجلات محدودة الحجم، دون userland-proxy
الملفات‎.env بصلاحية 600، المجلدات الشخصية 750، مجلدات cron للجذر، المترجمات للجذر في الإنتاج، Postfix المحلي دون VRFY وعلى loopback

كل خطوة تفحص قبل أن تكتب، فإعادة التشغيل لا تغيّر شيئا (القياس: --check بعد --apply أعاد «0 تغيير»).

4. المنافذ المكشوفة (nmap)

قبلبعد
TCP80/tcp http، 443/tcp https80/tcp http، 443/tcp https
UDP443/udp https443/udp https

لا قاعدة بيانات ولا Valkey ولا NATS ولا Keycloak ولا واجهة برمجية مكشوفة: كلها على 127.0.0.1 أو داخل شبكة Docker، والمدخل الوحيد هو Caddy (80 يحوّل إلى 443). المنفذ 443/udp لبروتوكول HTTP/3. الجدار الناري لا يغيّر هذه القائمة لأنها كانت ضيقة أصلا؛ دوره منع أي خدمة تُضاف لاحقا عن طريق الخطأ.

لا ثغرة معروفة (Heartbleed، CCS، ROBOT، POODLE، BEAST، LUCKY13، SWEET32، FREAK، LOGJAM، DROWN): البروتوكولات المعروضة TLS 1.2 و TLS 1.3 فقط، وكل الشفرات بتبادل مفاتيح ECDHE وتشفير AEAD.

الملاحظات المتبقية كلها عن الشهادة المحلية للعرض دون إنترنت، لا عن الإعداد. في التجربة والإنتاج تُستبدل بشهادة من بنية مفاتيح الديوان أو من ACME (المتغير CADDY_TLS)، ويُعاد القياس.

7. لإعادة القياس على خادم التجربة

sudo apt install lynis nmap testssl.sh
sudo infra/security/audit.sh before <IP> api.<domain>
sudo ADMIN_NET=<admin network> infra/security/harden-host.sh --apply --profile prod
sudo infra/security/audit.sh after <IP> api.<domain>
python3 infra/security/compare.py audit-before audit-after > hardening.json
python3 docs/deliverables/security/hardening_report.py hardening.json > docs/security/hardening-report.html

ويبقى قبل الإطلاق: فحص ZAP للواجهة البرمجية بحساب عون، واختبار اختراق خارجي، وتدقيق الوكالة الوطنية للأمن السيبراني (معايير القبول، الملف الوصفي §9.2).
