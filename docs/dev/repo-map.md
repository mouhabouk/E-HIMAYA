# قائمة «تطوير النظام»: نافذة SQL وخريطة المنظومة

طلب يامن 2026-11-09: قائمة جديدة لمدير النظام الوطني بعنوان «تطوير النظام»، فيها:

| العنصر | المسار | الوصف |
|---|---|---|
| نافذة SQL | `/sql` | محاكاة SGBD للقراءة فقط (`docs/sql/console.md`). |
| خريطة المنظومة | `/dev/map` | خريطة تفاعلية (graphify) لكل عناصر المستودع وروابطها. |

القائمة تظهر لمدير النظام ذي النطاق الوطني فقط، ويمكن إخفاء كل صفحة من «الصلاحيات» (المجموعة `dev`، المفتاحان
`sql_console` و`repo_map`).

## خريطة المنظومة

العناصر: صفحات لوحة القيادة والبوابة، وأجزاء تطبيق الهاتف، ووحدات الواجهة البرمجية (`services/api/app/modules/*`
و`core`)، والخدمات (ai، vision، telephony...)، والبنية التحتية (PostgreSQL، Valkey، NATS، Keycloak، MediaMTX...)،
والخدمات الخارجية. حجم العنصر بحسب عدد أسطر الكود.

الروابط:
- **طلب HTTP** (أزرق): مسارات `/api/v1/...` في كود الواجهات، مطابَقة مع موجّهات FastAPI. تفاصيل العنصر تعرض المسارات.
- **استيراد كود** (رمادي): `from app.modules.x` في Python، و`import` في TypeScript وDart.
- **اتصال بخدمة** (برتقالي متقطع): إعدادات `*_url` في الخادم.

في الصفحة: بحث، وتصفية حسب نوع العنصر ونوع الرابط، وسحب للتحريك، وعجلة للتكبير، ونقرة على عنصر تُبرز روابطه وتعرض
«يستعمل» و«يستعمله». الرسم من كود اللوحة نفسها (محاكاة قوى صغيرة، دون مكتبة ولا CDN، فيبقى ضمن سياسة CSP).

## التوليد

الخريطة لقطة من المستودع، يولّدها سكربت بمكتبة Python القياسية وحدها:

```
python3 -I scripts/repo_map.py . services/api/app/modules/devtools/repo_map.json
```

يُعاد تشغيله في نهاية كل مرحلة (مع بقية تحديثات `docs/phase-end.md`) أو بعد إضافة صفحات ووحدات. الواجهة
`GET /api/v1/admin/dev/repo-map` تقرأ الملف المرفق مع صورة الخادم، وتعرض الصفحة تاريخ توليده.
